# Security Policy

## Supported Versions

Security fixes will be backported to the latest tagged release. Older versions may receive fixes on a best-effort basis.

## Reporting a Vulnerability

1. Email the maintainers privately (update this section with a dedicated security contact address).
2. Provide a clear description, reproduction steps, and any proofs-of-concept.
3. Allow a reasonable disclosure window (at least 30 days) before publicizing the issue.

Please do **not** open public GitHub issues for vulnerabilities.
